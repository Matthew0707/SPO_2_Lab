# Лабораторная работа №2 — Метрика Джилба (Python)

Веб-приложение для расчёта метрики Джилба по исходному коду на Python.

🔗 **Онлайн-версия (GitHub Pages):** https://Matthew0707.github.io/SPO_2_Lab/

---



## Возможности

- 📝 Ввод Python-кода вручную или загрузка `.py`-файла
- 🔍 Подсчёт управляющих конструкций (`if`, `elif`, `for`, `while`, `match/case`)
- 📊 Подсчёт операторов (арифметических, логических, сравнения, вызовов функций)
- 📈 Расчёт метрик **CL**, **N_ops**, **cl**, **CLI**
- 🧩 Поддержка `match/case` с учётом вклада каждого `case` в сложность
- 🌳 Учёт вложенности условных конструкций

---

## Как пользоваться

1. Откройте сайт по ссылке выше 
2. Вставь Python-код в текстовое поле **или** нажми **«Открыть .py»** и выбери файл
3. Нажми **«Анализировать»**
4. Справа появятся метрики и таблицы:
    - список найденных управляющих конструкций с вкладом в `CL`
    - полный подсчёт операторов для `N_ops`

Кнопки **«Загрузить пример»** и **«Очистить»** помогают быстро начать.
